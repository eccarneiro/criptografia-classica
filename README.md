# Criptografia Clássica

Implementações das criptografias clássicas para a disciplina de Segurança da Informação.

## Cifras implementadas

| Cifra | Pasta | Autor |
|-------|-------|-------|
| Cifra de César | `/cesar` | - |
| Cifra de Vigenère | `/vigenere` | Ygor |
| Cifra de Substituição Monoalfabética | `/substituicao` | - |
| Cifra de Transposição | `/transposicao` | Elton |

## Como executar cada cifra

Entre na pasta da cifra desejada e execute o arquivo `.py`:

```bash
cd vigenere
python vigenere.py
```
