
# Cifra de Substituição monoalfabética

Também conhecida como cifra de substituição simples, é uma cifra onde
cada letra do texto original é substituída por outra letra do alfabeto.
É utilizada uma chave fixa que consiste nas 26 letras de um alfabeto
embaralhado.
A mesma chave é usada tanto para criptografar quanto para descriptografar
a mensagem.

**fonte**: [https://www.101computing.net/mono-alphabetic-substitution-cipher/](https://www.101computing.net/mono-alphabetic-substitution-cipher/)

Para realizar o embaralhamento, retira-se as letras repetidas da chave, posiciona ela no início, e preenche o restante do alfabeto embaralhado com as letras que ainda não foram usadas (em ordem alfabética).
